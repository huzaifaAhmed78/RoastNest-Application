# RoastNest — Responsive Figma-inspired Landing Page

A single-page responsive implementation based on the supplied `Home-10.pdf` Figma export.

## Run
Open `index.html` in a browser. No build step is required.

## Included
- Responsive desktop/tablet/mobile layout
- Hero, About, Features, Reservation, Testimonials, Stats, Order, Menu, Newsletter and Footer
- Mobile navigation
- Scroll reveal animations
- Hover/focus transitions
- Menu category filtering
- Newsletter interaction
- Add-to-cart micro interaction
- External food/restaurant imagery via Unsplash URLs

The supplied PDF uses placeholder copy in several places, so those sections retain the same placeholder-style wording where appropriate.
